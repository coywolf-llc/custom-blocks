# Coywolf Custom Blocks

> [!IMPORTANT]
> Coywolf Custom Blocks is no longer developed. Coywolf moved all of its sites from WordPress to [EmDash](https://emdashcms.com), and the plugin features it still uses are now in [Coywolf Pack for EmDash](https://github.com/coywolf-llc/coywolf-pack). This repository is archived and read-only.

## Use Coywolf Pack instead

Coywolf Pack doesn't include a block builder. The blocks Coywolf built with this plugin are in Coywolf Pack's [Custom Blocks](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/custom-blocks.md) module (Note, Details, Affiliate disclosure, Quote, Testimonial and Podcast links) and its [Reviews](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/reviews.md) module (the review box, with Review schema).

To add Coywolf Pack to an EmDash site, follow its [Getting started](https://github.com/coywolf-llc/coywolf-pack#getting-started) guide.

## What this plugin did

Let you create custom blocks in WordPress with an admin interface and a simple templating system, and export and import them between sites. It was a privacy-respecting fork of [Genesis Custom Blocks](https://github.com/studiopress/genesis-custom-blocks).

## If you still use it

The last release, [v1.0.74](https://github.com/coywolf-llc/custom-blocks/releases/tag/v1.0.74), is still available, but it won't get updates, security fixes or support. The code stays here under the GPL-2.0-or-later license.
